# 🎮 Proyecto Pokémon en Java

Aplicación desarrollada en Java que simula un sistema de combate entre Pokémon utilizando Programación Orientada a Objetos (POO), herencia, interfaces y asociación entre clases.

---

## ⚙️ Funcionalidades

- Creación de Pokémon de distintos tipos (Fuego, Agua, Planta)
- Asociación entre entrenadores y sus Pokémon
- Simulación de combate basada en nivel
- Visualización de información mediante `toString()`

---

## 🧠 Conceptos aplicados

- Programación Orientada a Objetos (POO)
- Herencia (`extends`)
- Interfaces (`implements`)
- Polimorfismo
- Encapsulación (getters y setters)
- Asociación entre clases
- Sobrescritura de métodos (`@Override`)

---

## 🛠️ Tecnologías utilizadas

- Java
- Eclipse IDE
- GitHub

---

## ▶️ Cómo ejecutar el proyecto

1. Abrir el proyecto en Eclipse.
2. Ejecutar la clase `CasoPractico1.java`.
3. Observar la simulación del combate en consola.

---

## 🧪 Ejemplo de ejecución

==== DATOS DE ENTRENADORES ====
Entrenador [nombre= Ash, experiencia= 1200, edad= 15, ciudad= Pueblo Paleta, companero= Charmander]
Pokemon de Ash : Pokemon: Charmander | Nivel: 12 | Tipo: Fuego

Entrenador [nombre= Misty, experiencia= 1100, edad= 16, ciudad= Ciudad Celeste, companero= Squirtle]
Pokemon de Misty : Pokemon: Squirtle | Nivel: 10 | Tipo: Agua

=== COMBATE ===
Combate [pokemon1= Charmander , pokemon2= Squirtle]
Resultado: Gana Charmander
