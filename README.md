# Proyecto Pokémon en Java

Aplicación desarrollada en Java como práctica de Programación Orientada a Objetos (POO).

##  Descripción
Este proyecto simula un sistema básico de combate entre Pokémon, utilizando clases, herencia y relaciones entre objetos.

##  Estructura del proyecto
- Clase `Pokemon` (clase base)
- Clases derivadas: `PokemonFuego`, `PokemonAgua`, `PokemonPlanta`
- Clase `Entrenador`
- Clase `Combate`
- Clase principal `CasoPractico1`

##  Funcionalidades
- Creación de Pokémon con diferentes tipos
- Asociación entre entrenadores y sus Pokémon
- Simulación de combate entre Pokémon
- Uso de métodos y atributos en clases

##  Conceptos aplicados
- Programación orientada a objetos
- Herencia
- Encapsulación
- Asociación entre clases
- Uso de métodos

##  Tecnologías
- Java
